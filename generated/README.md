# Generated Code (generated/)

This directory contains C source code automatically generated by the NetLang compiler.

## Contents

- **Network C files** (e.g., `mnist.c`, `lenet.c`): Generated inference code
- Each file is a standalone C program implementing the network architecture
- Generated from `.nlang` network definitions

## Generation Process

```bash
# Compile .nlang to C
build\netlang.exe examples\mnist.nlang -o generated\mnist.c

# The generated C code includes:
# - Network structure definitions
# - Memory allocation for activations
# - Layer-by-layer inference implementation
# - Weight loading from .nwf files
# - Optimized kernels from src/codegen/kernels.c
```

## Generated Code Structure

Each generated file contains:

```c
// Network state structure
typedef struct {
    WeightFile* weights;
    float* layer_0;  // Activation tensors
    float* layer_1;
    // ... per layer
} NetworkState;

// Initialization: load weights, allocate memory
NetworkState* network_init();

// Inference: input → output
void network_infer(NetworkState* net, float* input, float* output);

// Cleanup
void network_destroy(NetworkState* net);

// Main function (if enabled)
int main(int argc, char** argv);
```

## Compilation

Compile generated code with:

```bash
# Windows
gcc -O3 -march=haswell -mavx2 -mfma ^
    generated\mnist.c ^
    src\codegen\runtime.c ^
    src\codegen\kernels.c ^
    -o bin\mnist.exe

# Linux/macOS
gcc -O3 -march=haswell -mavx2 -mfma \
    generated/mnist.c \
    src/codegen/runtime.c \
    src/codegen/kernels.c \
    -o bin/mnist
```

## Optimizations

The generated code includes:
- **Shape specialization**: All tensor shapes known at compile time
- **Aligned memory**: 64-byte alignment for AVX2 loads/stores
- **Operator fusion**: ReLU fused into Conv2D/Dense layers
- **Static allocation**: No dynamic memory in inference path

## Notes

- Generated files are **not** tracked in git (see `.gitignore`)
- Code is human-readable for debugging and verification
- Can be manually edited for experimentation (use at your own risk!)
- Regenerate by running the compiler again
