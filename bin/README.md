# Binary Executables (bin/)

This directory contains compiled network inference executables generated by the NetLang compiler.

## Contents

- **Network executables** (e.g., `mnist.exe`, `lenet.exe`): Compiled network inference programs
- Each executable corresponds to a `.nlang` network definition compiled with `netlang`

## Usage

After compiling generated C code:

```bash
# Generate C code
build\netlang.exe examples\mnist.nlang -o generated\mnist.c

# Compile to executable
gcc -O3 -march=haswell -mavx2 -mfma ^
    generated\mnist.c ^
    src\codegen\runtime.c ^
    src\codegen\kernels.c ^
    -o bin\mnist.exe

# Run inference
bin\mnist.exe test_image.png
```

## Performance

These executables use:
- **AVX2 SIMD vectorization** for 6-8x speedup over scalar code
- **FMA instructions** for 2x MAC throughput
- **Memory-mapped weight loading** (~1ms startup time)

Expected inference times (single image, Intel i5-5200U):
- LeNet/MNIST: ~4ms
- MobileNet: ~8ms
- ResNet50: ~20ms
- VGG16: ~30ms

## Notes

- Executables are standalone and require only the corresponding `.nwf` weight file
- Optimize compilation with `-O3 -march=haswell -mavx2 -mfma` for best performance
- This directory is ignored by git (see `.gitignore`)
